Anthropic 产品设计负责人 · 主导 Claude 设计 · 前 Airtable / Quora 设计负责人

ux
美国产品设计师,Anthropic 产品设计负责人,主导 Claude 及公司 API 产品的设计。此前曾在 Airtable(End User Design 负责人)、Quora、Hustle、GoodGuide 带领设计团队,长期关注「软件工艺」与马斯洛需求底层问题（健康、安全、经济）的交叉地带。在 Anthropic,他把「先把可用原型丢进真实环境跑,再做研究」的方法带进 AI 产品设计,并主导 Claude Artifacts（2024 年上线,让对话即时生成可运行界面）等标志性功能;把 Claude 的人格设计成会推回、会较劲的「陪练」,而非一味顺从的助手。是 AI 时代「为不确定的模型行为做设计」这一新命题的代表性实践者。

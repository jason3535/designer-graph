Greg Christie

Apple alum

前苹果 HI 副总裁（2002-2014）

ux
美国 UI 设计师。1996 加入苹果，2002-2014 担任 Human Interface Group 副总裁。主导 Newton OS、Mac OS X、iPhone、iPad UI 设计。「Slide to Unlock」专利的合作发明人。在 Steve Jobs 时代直接对 Jobs 汇报，管理苹果整个 UI 设计团队。2014 离开苹果。
